# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En corto: trata a los demás con respeto, critica ideas y no a personas, y recuerda que aquí se viene a escribir poemas con forma de gato.

Para reportar un comportamiento inaceptable, escribe a maosuarezbarrer@gmail.com. Los reportes se tratan con confidencialidad.
